# -LAB-16-Ma-triser-les-Services-dans-une-Application-Android

Ce projet consiste à développer une application Android nommée Chronomètre Service en Java, permettant de mesurer le temps écoulé grâce à un Service Android exécuté en arrière-plan.

# Fonctionnalités principales
Démarrage du chronomètre depuis l'interface.
Arrêt du chronomètre à tout moment.
Exécution en arrière-plan grâce à un Foreground Service.
Affichage du temps écoulé dans une notification persistante.
Communication entre l'Activity et le Service via un Bound Service.
Respect des restrictions Android récentes concernant les services en arrière-plan.
# Objectif pédagogique

Comprendre et maîtriser l'utilisation des Services Android, leur cycle de vie, les Foreground Services, les Bound Services ainsi que la gestion des notifications persistantes dans une application mobile Android
